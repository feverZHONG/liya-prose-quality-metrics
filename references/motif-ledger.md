# 母题／物件账 · 某个东西「本身」怎么被处理

> 什么时候用：用户说「X 本身」「还有一件事没考虑到位」「似乎还没有视角去考虑这件事」；或自己怀疑某个母题（翅膀／那道光／纸笔／旧画）在稿里只当零件用。
> 铁律：**只报不改**。先落账（0 字改动）、给选项，等用户拍完方向再动笔。

## 一、逐节命中表（脚本化，不凭感觉）

按分节符（全稿一般是 `\n---\n`）切节，逐节数关键词命中行数，输出「节 ｜ 命中行 ｜ 备注」＋每节行号摘句：

```python

lines = open(fn, encoding='utf-8').read().split('\n')
seps = [i for i, l in enumerate(lines) if l.strip() == '---']
bounds = [0] + seps + [len(lines)]
for k in range(len(bounds) - 1):

```

读法：

- **不存在于本篇的东西 0 处本身成立，但「贯穿要素」不能就这样放过**——还没长出翅膀的那一篇＝0 处；**别凭这一点就报「这一篇不动」**（实测被驳回：书名级的那个东西是贯穿要素，每一部分都要有落点）。写法见 §七。
- 信号在**分布**：某节只有 1 处而相邻节十几处，说明那一节没把它当要素用（或它在那一节还没有名字）。
- **行号一律回原文 grep 一遍再写进档**：同一段在工作稿与拆篇产物里的行号不同，凭印象写必错。

## 二、称呼演变（命名时刻＝情绪点）

逐节看它被叫什么：主角自己怎么叫它 → 谁第一次叫出正式名字。
实测样本：主角自己一路叫「背上那两块东西」，正式名字是**第二个人**给的（「你有翅膀了。」）——命名权在谁手里是关键信息，别漏。

## 三、三个渠道账（核心：它怎么被「看见」）

物件长在主角身上（翅膀／疤／背后的东西）时，主角的**体感**只是三条渠道之一。三个渠道各自数清处数：

| 渠道 | 查什么 | 典型证据 |
|:--|:--|:--|
| 主角自己 | 体感词（暖／软／沉／有劲／会自己动） | 满篇，但全是「从里往外」 |
| 别人的眼睛 | 第二个人对它的台词是**描述／评价**，还是只有**功能确认** | 「你有翅膀了」「摔了你也有翅膀」＝功能确认；**外形描述 0 处** |
| 间接证据 | 影子／倒影／声音／重量／回头一眼 | 影子 2 处、水面 2 处——主角看不见自己的背时，这些是唯一的「看见」 |

判词：**真缺口多半不是「它出现得少」，是机位只有一个**——全篇只从主角身上往外写。

## 四、未咬合的散笔

同一个机制在几处各闪一次（如「它自己动」四笔散在四节）＝读者读到的是 N 个「新奇」，不是一条线。列出行号＋所在节，写清「合起来已经是一句话，但没串」。

## 五、选项表与落点

- 三个方向：**它那一侧**（把散笔咬成一条线）／**外面的眼睛**（补一次「被看见」）／**主角自己那条间接看见的线**（影子·倒影·画）。
- 落点优先挂到**已有的收口物**（结尾那张大画、母题闭环句），通常 0～40 字。
- 要**加新事件**的方案最响，也最容易踩红线（不解释／配角不说长句）——**单开一议**，别混进小改一起报。
- 报告形：现状实测 → 选项（做什么／代价／风险）→ 推荐 → 待拍，末尾给一句「我的走法」（如「先跑 0 字的一路审稿 → 再按 A＋C 收线」）。
- 账落项目的过程稿目录（`核对/NN-…-怎么做.md` 一类）＋登记其 INDEX；用户点头前不动正文。

## 六、系列口径（多篇同世界观时）

同一样东西在「起源篇」与「日常篇／后日谈」里的呈现必须对得上：后日谈里公开、活着、被人围观的东西，起源篇不能一次都没被人正面看过。**定调改过之后（谁是谁的本源），旧的呈现账要重算一遍。**

## 七、贯穿要素：替身写法（本篇还没有它时）

用户点名「这是贯穿全文的要素」之后的落地口径：

1. **一个字不提它的名字**（起源篇里主角还没有它）。靠**本篇已有元素**的咬合承载——四个替身模板：**位置**（它将来长在哪里：背）／**它的介质**（风）／**它解决的缺失**（上不去）／**它将要改变的东西**（只会动的东西＝她现在只画得出风和水）。
2. **替身必须从原文里捞**：每条都要能指回本篇已经写到的一句（「烟往哪边倒，我就知道风从哪边来」「她背对着镇子」「屋顶我上不去」）——新造概念＝预告片，不是贯穿。
3. **微改优先**：每条 +15～60 字，一篇的替身合计常只有一两百字——**分量不在字数**，在「要素真正出场的那一节能指回来」。
4. **顺序：替身所在的那一部分先改**，立住之后才去写它出场那一节。
5. **禁止的写法**：替人物说出主题（「我画的东西都是走不动的」）、提前给预兆（她画里早就画过会飞的东西）——那是解释，比 0 处更糟。

## 八、追加单（A／B／C 三档）

- **A＝必然发生**（每条后跟一句「为什么本来就该发生」）／**B＝可选**／**C＝不建议并写清理由**（拦「堆描写」就靠这一栏）。
- 每条：**落点行号＋判据＋预估字数**；档末合计**用工具算**；**同一信息的两个落点必须标「取一」**——都留＝同一个信息拆两条，读者第二次就无感了。
- 落档前行号 grep 回原文核一遍（同 §一）。
- C 档要把「与已有的重复」写成显式否决理由（同一拍子第三遍播放＝删，不是加）；被标过「到顶」的节重开要单独请示。
