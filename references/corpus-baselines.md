# 基线是怎么量出来的（已发布语料）

> 用途：用户点出一类新的「平」（标点、短句、分行……）时，**先在已发布篇上量同一维度取区间**，再把区间写进 `scripts/prose-metrics.py` 的常量与 SKILL.md 的基线表。凭感觉定阈值一定定歪。

## 一、语料在哪

```
<数据根>/archive/bili-articles/articles/2026/cv*-【系列名】*/article.md
```

一篇一个目录；`article.md` 的正文前面有几行元数据（`文字：`／`大纲/校对`／`发布时间`／`#` 标题／`>` 引用块），量之前先剥掉（脚本里的 `strip_meta()` 就是干这个的）。

## 二、三条量法（可直接抄的片段）

```python
import re, glob, statistics
Q = re.compile(r'[「“]([^」”]*)[」”]')          # ⚠️ 两种引号都要算，见 §三

def prof(text):
    cjk = len(re.findall(r'[\u4e00-\u9fff]', re.sub(r'\s', '', text))) or 1
    marks = {m: round(text.count(m) * 1000 / cjk, 1) for m in '，。？！…—、'}
    flat = (text.count('，') + text.count('。')) / max(sum(text.count(m) for m in '，。？！…—、'), 1)
    return marks, flat

def split_dist(text):                        # 叙述 vs 台词 分开量
    q = [x.strip() for x in Q.findall(text) if x.strip()]
    narr = Q.sub('\n', text)
    def d(x):
        S = [y for y in re.split(r'[。！？…—]+|[；]', re.sub(r'\s', '', x)) if re.sub(r'[，、：]', '', y)]
        L = [len(y) for y in S]
        return (len(L), round(statistics.mean(L), 1), round(sum(1 for i in L if i <= 5) * 100 / len(L), 1)) if L else (0, 0, 0)
    return d(narr), (len(q), round(statistics.mean([len(x) for x in q]), 1),
                     round(sum(1 for x in q if len(x) <= 5) * 100 / len(q), 1)) if q else (0, 0, 0)

def para_dist(text):                          # 段均句
    ps = [p for p in re.split(r'\n\s*\n', text) if p.strip()]
    cnt = [max(len([y for y in re.split(r'[。！？…]+', p) if re.sub(r'[\s，、：]', '', y)]), 1) for p in ps]
    return len(ps), round(statistics.mean(cnt), 2), round(sum(1 for c in cnt if c == 1) * 100 / len(ps), 1)
```

## 三、三个陷阱（不信这些数会歪）

1. **引号有两种**：早期篇用 `“”`，后期篇用 `「」`。只数 `「」` 会把早期篇的台词全漏掉——台词均长、台词密度、标点谱的「台词尾标点」全偏。**一律用 `[「“]([^」”]*)[」”]`**。
2. **排版有两种体**：一种是**单换行**（一行即一段），一种是**空行分段体**。量「段均句／单句段」只能用空行分段体的篇（实测 3.0／3.1 就是从那两篇来的）；单换行体要先假定「一行＝一段」再量，不要拿空行分割去量它（会得到「全篇 4 段」这种废数）。
3. **元数据块会冒充段落，而且头部不止一层**：不剥掉 `#`／`>`／`文字：` 那些行，段数会少一大截、段均句会虚高。
   - ⚠️ **「【前排说明】」块的结束判定别等 `---`**：收稿下来的线上稿，说明块（`图源／文字／大纲·校对` 三五行）后面**常常直接就是正文，没有收尾的分隔线**。按「遇到 `---` 才结束」写，块状态会一路吞到文末——**整批样本的统计全变 0**（实测：18 篇的对话占比中位数一排 0.0，就是这种吃法，不是样本坏了）。**按块内已知前缀判结束**（`图源|文字|大纲|校对|封面|链接|排版`），遇到第一个不匹配的行＝正文第一行。
   - 剥完**自检长度**：随手挑一篇打 `len(body)`，几百字以下＝剥过头了；一批样本里出现「全部指标恰好为 0」也是同一个信号。

## 四、阈值会漂

基线的用处是「相对区间」，不是及格线：新篇发布后（或用户换了语料）**重新量一遍再改脚本常量**。写死常量时把量法出处一起写上（「15 篇已发布稿实测」），下次才知道要不要刷。
