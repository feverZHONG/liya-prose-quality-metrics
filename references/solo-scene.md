# 单人戏／独处镜头怎么写

> 2026-09-25 从独立 skill `solo-scene-craft` 整档并入（该 skill 与本库同域，独有判据占比 9/11）。

> 一个人在场的那一段，最容易写成两样：**跟不在场的人说话**（假），或**只剩动作、没有人在里面**（干）。
> 这一册只管一事：**人只剩一个的时候，声音从哪里来。** 口径是一条一条被纠正出来的——**对象只能是她自己**。

## 一、三条口径（先记这个，三条都撞过）

1. **不让别人应答。** 独处时**没有人回话**；配角只作「**在看**」存在（抬一下头、站在原地没动、也没上来），**不参与、不回话**。人只出现在**这件事开始之前**（叮嘱／出发）与**结束之后**（「我下来了，你先别问」），**中间不对话**。
   —— 实测被打回两次：① 写成与下面的人四个来回的喊话；② 改成「喊给风听／喊给这片空听」。**对象是人、是风、是空都不算**，因为接收者不是她自己。
2. **自我对话＝自己跟自己。** 每一句的接收者只有她一个——**交代事情给自己、催自己、否掉自己刚做的那一下**（「再高一点。」「这个圈不算，刚才那个不算，再来一次。」「往这边收。」）。
   可以出声、可以带引号（出声的自语也是自己跟自己）；**关键是对象只有自己**。是否出声不重要，**「说给谁」才重要**。
3. **三样动力：去感受、去呐喊、去享受**（比「想事情」对）。
   享受**一律挂在动作与身体上**——越说越顺、说完自己听了一下、多绕了小半圈、底下那个人只抬了一下头；**不写形容词**（与「情绪挂身体、不挂形容词」是同一条命）。

## 一·补、加自语的落笔纪律（红线在哪儿）

自语是独处段的肉，但它**不是普通台词**——按对话的常规写法落笔，会当场撞三条硬红线（xx说／一行一句／对话不带描述）。四条纪律：

1. **台词一律挂在动作上**（同一段内、描述在前、冒号接）。**单独成段的台词＝当场违规**——这跟双人篇不同：双人篇「一句一段」是节奏（有第二个人答话衬着），独处段里光秃秃一句台词既没归属也没伴随动作。
   → 推论：**独处段没有「纯台词段」是正常形态**，别为了凑段型比例去造；与「纯台词段 > 0」这类段型建议冲突时，**让位于硬红线并记放宽**。
2. ⚠️ **引导语里别用「说」**：「她低声**说了**半句：」「她自言自语**说**：」——「说」贴着引号＝直接命中 xx说。换成**不带「说」的动作**：「把声音压低：」「嘴里跟着念了一句：」「跟着报数：」「推了它一句：」。
3. **加完必须重跑硬红线检查**（那类一次性列出归零项的命令）。补对话会重新引入那三条——凭记忆跳这一步，就会带着一处违规交稿。
4. **撒点与用量**：**四到六处**（每做一件事挂一句）就够，声音全落在「手上的活」上——给东西下指令（对旧物件、对刚做好的东西、放走它的时候推一句）、对活儿的评价（「这面厚了，抹匀就没事。」）、跟着自己的手报数（「……五盏、六盏。」）。**别写成抲情独白**，也别把自语当连接词连着用。

## 一·补二、场上没有第二个人时，不许借第二双眼睛

> 与上一条「配角只作在看存在」的分界：**那些是可写「看」的场景（场上有旁人）；本节管场上一个人都没有的那种稿子**——这时连「有人在看」的痕都不许出现。

**判据一句话：这句话能不能一个人成立？** 凡是要靠「有个别人在／看见／没抬头／会回来」才成立的句子，都是越线。

| 越线写法 | 为什么 | 改法 |
|:--|:--|:--|
| 「窗里的锅上冒着一小团白汽」 | 冒汽的锅＝屋里有人（灶是人的生活痕） | 只留静物（那格窗亮着），或删 |
| 「里面谁也没抬头」 | 借了第二双眼睛当结论 | 换成没人的物：树还在、院门关着 |
| 「反正底下的人看见的也就是一个模糊的影子」 | 把「有没有人看」写进理由＝把第二双眼睛请回来 | 只留高度／只留风，不留「人」 |
| 镜头里出现一个在做事的人（哪怕背对、无声） | 具体的第二人在场 | 删人留物 |

**可以留的**：环境底噪**不是**第二视角——墙那头的电视声（听不清说什么）、谁家的窗子关了一下、楼梯口随时会有人上来。界限只有一条：**它有没有「看」或「说」**。

⚠️ **这类越线机器一处都不报**——红线命令只数引号与轮次，**数不出「这句话需要几个人才成立」**；只能靠人的通读与审读队（审读队派法见主 skill 铁律 2）。

## 二、念头怎么写

- **不用冒号引出。** 「一个念头上来，不长：跳下去」这类**冒号句**被明确否掉——改破折号或直接铺开（「她**想从那头出去一次**——那边的石头低下去，再过去什么都没有」）。同类「看见了：」「记住：」一并顺成破折号。
- **念头要落在动作之前**：落地→冒出念头→找到能去的地方→**才**跑起来。把念头放到动作之后当补注，读起来像事后解释。
- 自我对话**不必带引号**也能成立：用「她想的是／她心里就这一句／一个念头」引出即可——但**引出的内容要用破折号或直接铺开，不要用冒号**。

## 三、起止与留活口

- **开场**：独处那件事的触发物要具体（她看见了什么、脚底下是什么感觉），**别用决心/宣告开头**。
- **收尾**：不要写成「完成了」——留一个**能接下游的动作**，或一句**自己交代给自己的话**（「说是一圈，她又多绕了小半圈才把头低下去」）。
- **中途的转折**（怕了／不行了）要写成**她与自己的一句话**（「下去——这一句她想了两遍，人才动」），不写成向别人解释。

## 四、没有语料时：从参考作品拆手法（借心态，不借抒情）

用户说「看一下 X 是怎么写的」时，**不要模仿句子，要拆「它靠什么写成」**：

1. 读那一段，列出它实际用的**几根支柱**（实测一份参考作品的独自夜飞段＝① 内心话成串 ② 一样一样地试 ③ 意犹未尽再多绕一圈 ④ 享受之后才出事）。
2. 逐条问「**我们这条线能不能用**」——能借的借结构（自语的密度、试的次序、收尾的多余那一小圈），不能借的写清楚为什么。
3. **借心态，不借抒情**：参考作品若直抒胸臆（「那真是最最美妙的享受！」），而本条线的口径是**情绪词归零**，那就只借它的**节奏与结构**，抒情一律改挂动作与身体。——**把这条写进任务书**，否则接手的人会照着参考作品把形容词搬进来。
4. 拆完落一份「借了哪几条／不照搬哪几条」的短账，挂在那一节的大纲里。

## 五、交稿前自检（四问）

- 台词里有没有「**你**……」开头的句子？（在跟谁说话？——独处段里这就是 bug）
- 台词是不是**都挂在动作上**、引导语里**没有「说」**？（单独成段、或带「说了／自言自语说」＝当场违规）
- `grep -n '：'` 里有没有**引出念头／心里话**的冒号？
- 念头是不是落在**动作之后**当补注了？
- 场景里有没有一句**需要「别人存在」才成立**的？（有人在做事的痕、有人会看到的理由、借第二双眼睛下的结论——§一·补二）
- 「享受／痛快／自由」这类**形容词**是不是直接写出来了？（改成动作与身体）
